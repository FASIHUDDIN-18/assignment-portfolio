SUMMARY

1. Content: The actual information inside an HTML element, such as text or images.
2. Padding: The space between the content and the border.
3. Border: The line surrounding the content and padding.
4. Margin: The outer space around an element.
5. Box Sizing: Controls how the total width and height of an element are calculated.
