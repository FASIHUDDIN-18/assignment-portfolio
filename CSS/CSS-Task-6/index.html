Combinators – All 4 Types

Select elements based on their relationship

Descendant Combinator (Space)





Selects all matching elements inside a parent element.

Exp:For Tag

div p {
                color: red;
}





Exp:Select all element!

<div>
<p> Text </p>

<p> Text </p>
</div>





child Combinator (>)





Selects only the direct chlidren of a parent element.

Exp:For Tag

div p {
                color: red;
}





Exp: Element

<div>
Selected
<p> Direct Chlid </p>

Not Selected
<div>
<p> Text </p>
</div>
</div>





Adjacent Sibling Combinator (+)





Selects the first matching element immediately after another element.

Exp:For Tag

div p {
                color: red;
}





Exp: Element

<div>
<p> Text </p>

Selected

<p> First Paragraph</p>

<p> Second Paragraph</p>
</div>









General Sibling Combinator (~)




Selects all sibling element that come after another element.

Exp:For Tag

div p {
                color: red;
}





Exp: Element

<div>
<p> Text </p>

Selected

<p> Para 1</p>

<p> Para 2 </p>

<p> Para 3 </p>

</div>
